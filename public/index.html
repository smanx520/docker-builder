Docker Builder GitHub 一键打包成 Docker 镜像

把 GitHub 仓库打包成 Docker 镜像

输入仓库地址检测权限 → 选择分支 / Tag → 登录 GitHub 并配置打包选项 → 一键触发 GitHub Actions 构建并推送到镜像仓库。构建运行在 docker-builder 仓库，目标仓库只需可读取（公共仓库直接克隆，私有仓库填 Token）。

1仓库检测与版本
2打包配置
3构建进度
1

仓库检测与版本

说明：公共仓库无需 Token 即可直接检测；私有仓库需要一个能读取它的 Token。

默认使用所选分支的最新代码；也可在右侧下拉选择某个 Tag 固定版本打包。构建时会自动检测所选版本是否包含 Dockerfile。

2

打包配置

Token 仅保存在浏览器本地，请求时随 Authorization 头发送，不会上传到其它位置。

登录后可检查构建宿主 fork 状态 去 fork / 开启 Actions

在「GitHub 登录」与「手动 Token」中二选一完成认证并检查 fork 状态，再填写打包所需信息（推送到 Docker Hub 时才需要其凭据），即可开始打包。
